# Lab 1: Build a Grocery List

This is a single, one-hour React lab. The app runs locally with npm and Vite. Tailwind is already configured. There is no database or backend; new items stay in memory until the page refreshes.

You need [Node.js](https://nodejs.org/) 20.19+ or 22.12+ and npm.

## Start

Open this `lab-1` folder in VS Code. In its terminal run:

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`). The starter page should say “Grocery Helper 🛒”.

**Edit only `src/App.jsx`.** The `index.html` page and other setup files are complete. Use [WALKTHROUGH.md](WALKTHROUGH.md) to type the app with the class. [APP_Finished.jsx](APP_Finished.jsx) is a reference, not an imported file. To try the finished version directly, copy its contents into `src/App.jsx`.

For a published repository, students can run `git clone REPOSITORY_URL`, open the cloned folder, then run `npm install` and `npm run dev`. Share the real repository URL once the instructor publishes it. `node_modules`, `dist`, and local environment files are ignored by Git.
